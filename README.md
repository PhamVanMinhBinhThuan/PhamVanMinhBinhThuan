**Internship project · Viettel Digital Talent 2026 · Viettel Cyber Security**

**Highlights:**
- Built a full-stack application with **React/TypeScript, Spring Boot, Elasticsearch, PostgreSQL, and LLM integration**
- Designed a controlled query pipeline:  
  **natural language → structured SearchPlan → backend validation → executable query**

- Deployed with **HTTPS** and **GitHub Actions CI/CD**
